# LOCK-IN & ROAST — FOCUS

This repository contains a starter Progressive Web App for "LOCK-IN & ROAST" — a high-energy productivity app with a roast mechanic.

What's included
- Vite + React app skeleton
- PWA manifest and service worker (public/sw.js)
- Install banner for Add to Home Screen
- Focus timer with circular SVG ring
- Page visibility detection and violation handling
- Roast overlay with text-to-speech and audio
- Proof scanner simulation and downloadable shame card generator

How to run locally
1. Install dependencies: npm install
2. Run dev server: npm run dev
3. Open the app at the printed local URL

Notes
- This is a front-end only demo. Server-side app-blocking or native blocking is NOT possible purely from web pages. The app simulates block attempts and provides audiovisual deterrents.
- Ensure Notifications and Microphone/Audio are allowed in the browser for best experience.
